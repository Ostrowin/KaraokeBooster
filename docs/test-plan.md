## Affected Pages/Routes
- CLI `tools/ultrastar2midi.py`: konwersja UltraStar → MIDI (nuty, sylaby, CC bypass) i kontrola wyrównania z vocals.wav
- `tools/lyrics_viewer.py`: tekst zsynchronizowany z transportem REAPER przez OSC
- `tools/analyze_takes.py`: metryki (a), (b), (c) i skuteczność detektora początków sylab
- Moduł `karaokebooster/ultrastar.py`: wspólny parser dla trzech narzędzi

## Key Interactions to Verify
- Plik UltraStar (UTF-8, UTF-8 BOM, CP1250 z #ENCODING, CP1250 bez tagu) daje identyczne nuty i poprawne polskie litery
- Czas nuty = GAP/1000 + beat·60/(BPM·4); w MIDI ticki przy 120 BPM / PPQ 960 zgadzają się z sekundami (±1 tick)
- #RELATIVE, #START, #END, #AUDIO ma pierwszeństwo przed #MP3
- Nuty F/R/G nie trafiają do MIDI; przerwy i F/R/G mają CC bypass; sylaby jako lyric events
- `--octave N` przesuwa wszystkie nuty; scalanie nut krótszych niż X ms
- Kontrola wyrównania ostrzega przy przesunięciu > 30 ms i milczy przy dobrym wyrównaniu
- Podgląd tekstu: start, pauza, przewinięcie w REAPER; podgląd trzyma pozycję, gdy OSC milknie
- analyze_takes: (a) na syntetycznym tonie o znanym błędzie, (b) z ręcznego CSV, skuteczność detektora w oknie ±50 ms

## Edge Cases
- Duet P1/P2 → błąd; błędna linia → błąd z numerem linii; #VIDEO i nieznany tag → ostrzeżenie
- Pusty plik / brak nut / brak #BPM → czytelny błąd
- Wokal Demucs cichy lub bez początków → ostrzeżenie kontroli wyrównania, bez crasha
- Brak pliku CSV ze znacznikami / pusty CSV → czytelny błąd analizy
- Ton przesunięty o oktawę względem celu → (a) liczy błąd mod 12

## Critical Paths
- [E2E] .txt + syntetyczny wav → ultrastar2midi → MIDI + raport wyrównania (bez Demucs)
- Ręcznie: jedna piosenka Krawczyka end-to-end w REAPER (krok 4-7 dokumentu) po imporcie MIDI bez mapy tempa, audio z podstawą czasu Time
